# Wave 3 curriculum contract

Каждый агент правит только свои `course/weeks/week-*.ts`. Не трогать `course/types.ts`, `course/index.ts`, `course/curriculum.ts`, `course/glossary.ts`, UI, тесты, `docs/audit` кроме своего отчёта в ответе.

Голос: русский, короткие предложения, без длинного тире, как соседние недели. Не переписывать неделю. Добавлять измерение, сбой и поля контракта.

Обязательно, если поля ещё пустые:

- `learningObjectives`: 4 проверяемых исхода, уже вытекающих из недели.
- `experiments`: один, совпадающий с лабораторией.
- `failureModes`: 2, с symptom, cause, check.
- `metrics`: то, что студент записывает сам. Не выдавать чужие числа за факт.
- `artifactRubric`: ровно 4 критерия, веса 25. Сумма 100.
- `sources`: хотя бы один `CourseSource`. URL только тот, который уже есть в неделе, либо официальный, в котором вы уверены. `checkedAt`: `2026-09-21`. `kind`: `official-docs` или `paper`.
- `contentVersion`: `2026.09`.
- `lastReviewedAt`: `2026-09-21`.
- `securityNotes`, `privacyNotes`, `costNotes`: по одной короткой строке, только если тема недели это уже содержит или вы добавили конкретный шаг.

Квиз: существующие id не менять. `passScore` остаётся 70. Если вопросов меньше 8, добавить через `q()` до 8. Смешивать `conceptual`, `scenario`, `architecture`, `debugging`. Индекс ответа внутри массива options.

Запрещено: TODO, FIXME, placeholder, coming soon, скоро будет.

Лаборатория: таблица, которую студент заполняет своим прогоном. Один контролируемый сбой. В рефлексии вопросы error analysis: что не сработало, на каких примерах, почему, как проверить гипотезу, что изменено, стало ли лучше, чем это доказано.

Новый урок добавлять только если тема не помещается в существующую лабораторию. Объём текста сам по себе не является глубиной.

Термин для глоссария оформлять как INTEGRATION REQUEST, файл глоссария не менять.
