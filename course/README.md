# Курс

Типизированная программа: 32 учебные недели и отдельный Capstone (slug `capstone`). Модули, уроки, лабы, практика, промпты, квизы, артефакты.

Недели регистрируются в `course/index.ts`. У Capstone поле `id` равно 33, в интерфейсе это не неделя 33.

Как добавлять материалы: `docs/architecture/content-schema.md`.
Полная карта: `docs/curriculum/32-week-map.md`.

`course/legacy/` — архив старого 6-недельного контура, не часть живого курса.
