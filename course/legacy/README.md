# Архив: 6 недель

Файлы в этой папке — исторический 6-недельный контур. Они не входят в живой курс.

`tsconfig.json` исключает `course/legacy`. TypeScript их не проверяет, приложение их не импортирует.

Живая программа собирается в `course/index.ts`: 32 учебные недели и отдельный Capstone (slug `capstone`).
